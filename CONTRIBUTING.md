# Contributing

Improvements to the SKILL.md prompt are welcome — open a PR with before/after examples showing the change.

## How

1. Fork repo
2. Edit `skills/tokenzip/SKILL.md` — this is the only copy you need to touch
3. Open PR with:
   - **Before:** what tokenzip say now
   - **After:** what tokenzip say with change
   - One sentence why change better

> **Note:** `tokenzip/SKILL.md`, `plugins/tokenzip/skills/tokenzip/SKILL.md`, `.cursor/skills/tokenzip/SKILL.md`, and `tokenzip.skill` are auto-synced by CI after merge. Do not edit them directly.
> 
> **Note on compress skill:** If you are modifying the compress skill, edit `tokenzip-compress/SKILL.md` or `tokenzip-compress/scripts/`. CI will automatically sync these changes to `skills/compress/` and `plugins/tokenzip/skills/compress/`.

Small focused change > big rewrite. TokenZip like simple.
